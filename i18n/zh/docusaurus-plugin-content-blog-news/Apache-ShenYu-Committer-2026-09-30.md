在调研 API 网关的过程中，我发现了 Apache ShenYu —— 一款高性能的 Java 原生 API 网关。

优秀的 API 网关在业务系统中发挥着至关重要的作用，它是服务对外提供访问的关键入口。随着对 ShenYu 了解的不断深入，我越来越被它出色的架构设计、整洁的代码风格等诸多优点所吸引。
