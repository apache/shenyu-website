## 2.7.2

Apache ShenYu 2.7.2 includes the complete changes from v2.7.1 through the
approved RC4 candidate.

## What's Changed

- Replay one-shot request bodies and preserve downstream errors in Request Transformer.
- Honor fail-closed sensitive-word inspection when Redis is unavailable.
- Decode JSON text, including Unicode escapes, before sensitive-word inspection.
- Scope Token Limiter usage accounting to provider protocol fields.
- Align the dependency baseline with Spring Boot 3.5 and Spring Cloud 2025.0.3.
- Correct Maven and distribution LICENSE/NOTICE materials and validate source archives.
