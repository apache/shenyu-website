### 个人介绍

我是 Jinze Song。我对 AI Gateway 如何通过模型上下文协议（MCP）聚合工具感兴趣。我的 GitHub 账号是 [BobSong-dev](https://github.com/BobSong-dev)。

### 初识 Apache ShenYu

我通过开源之夏（OSPP）第一次接触到 Apache ShenYu。为了参与 Agent Gateway 开发，我开始仔细阅读网关代码。后来提交 PR 时，我也在一次次评审讨论中逐渐认识了维护这些代码的社区伙伴。

### 开源贡献与成长

我参与了 Agent Gateway 中请求级上下文（request-scoped context）相关功能的开发。除了关注网关如何聚合 MCP 工具，这段经历也让我开始思考另一个问题：一次请求经过网关时，哪些信息应该只属于这次请求？在和评审者讨论改动的过程中，我学会了在 PR 中解释这些边界，让读代码的人也能理解我为什么这样改。

### 致谢

感谢我的导师 Hongyu Liu（Aias00）在技术开发中给予指导，也带我参与社区讨论。感谢每一位读过我的补丁、提出问题并花时间给出修改建议的社区伙伴。

### 未来展望

成为 Committer 后，我想继续维护 Agent Gateway 的代码，也想投入更多时间评审 PR。我希望能在社区里分享自己对 MCP 和工具聚合的理解，帮助新贡献者找到参与项目的切入点，就像我在开源之夏得到的帮助一样。
