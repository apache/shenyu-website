### 个人介绍

大家好，我是 Jinze Song，GitHub 账号为 [BobSong-dev](https://github.com/BobSong-dev)。我主要关注 Java 后端开发、API 网关以及 AI Agent 工程化，对 MCP 与网关技术的结合尤其感兴趣。

很荣幸能够成为 Apache ShenYu Committer。这段经历对我而言是一次重要的成长，也意味着未来需要承担更多社区责任。

### 初识 Apache ShenYu

我通过开源之夏（OSPP）开始参与 Apache ShenYu 社区。最初，我从阅读项目源码、熟悉整体架构入手，逐渐将关注点转向 Agent Gateway 相关功能的开发。

随着参与的深入，我开始接触更多网关底层设计与工程实践，也逐渐认识到，一个成熟的开源项目不仅需要功能的持续迭代，更需要社区成员之间充分的沟通、协作与经验积累。

### 开源贡献与成长

在 Apache ShenYu 的贡献过程中，我主要参与了 Agent Gateway 方向的开发工作，包括请求级上下文（request-scoped context）相关功能的设计与实现，以及 MCP 相关能力的探索与开发。

这些工作让我有机会深入理解网关请求处理链路、上下文管理机制，以及 AI 能力与传统网关架构相结合时所面临的工程问题。

在实际开发中，我逐渐认识到，完成代码实现只是贡献的一部分。理解现有架构、考虑不同场景下的行为、保证改动的可维护性，以及在 Pull Request 讨论中清晰表达设计思路，同样重要。

通过一次次代码评审和技术交流，我不仅积累了工程实践经验，也对开源协作和高质量软件开发有了更深的理解。

### 致谢

特别感谢我的导师 Hongyu Liu（Aias00）在技术开发和社区参与过程中给予的指导与帮助。

同时，也感谢 Apache ShenYu 社区的每一位成员。无论是代码评审中的细致建议，还是日常技术交流中的经验分享，都让我受益匪浅。感谢大家共同营造了一个开放、友好且乐于协作的开源社区。

### 未来展望

成为 Apache ShenYu Committer 对我而言是一个新的起点。

未来，我希望继续深入参与 Agent Gateway 及相关能力的建设，在持续贡献代码的同时，积极参与 Pull Request Review、Issue 跟进和社区技术交流。

我也希望能够将自己在开源实践中积累的经验分享给更多开发者，帮助新的贡献者更顺利地融入社区。

期待与 Apache ShenYu 社区的伙伴们继续并肩前行，共同推动项目发展。
