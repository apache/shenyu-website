VERIFY YOUR DOWNLOAD

校验下载文件

使用前请校验发行包的签名与校验和。从 Apache 下载 KEYS 及对应的 ASC、SHA-512 文件。

下载签名公钥（KEYS） ↗

01验证 PGP 签名

以下以当前选中的源码版本为例。将发行包、对应的 ASC 签名及 KEYS 放在同一目录，然后执行：

gpg --import KEYS
gpg --verify apache-shenyu-2.7.1-src.zip.asc apache-shenyu-2.7.1-src.zip

02比对 SHA-512 校验和

根据操作系统执行相应命令，将输出与下载的 SHA-512 文件内容进行比对。

# Linux
sha512sum apache-shenyu-2.7.1-src.zip

# macOS
shasum -a 512 apache-shenyu-2.7.1-src.zip
