### Personal Introduction

I'm Jinze Song. I'm interested in how AI gateways bring tools together through the Model Context Protocol (MCP). You can find me on GitHub at [BobSong-dev](https://github.com/BobSong-dev).

### Discovering Apache ShenYu

I first came across Apache ShenYu through Open Source Promotion Plan (OSPP). Working on the Agent Gateway gave me a reason to read the gateway code closely. As I submitted pull requests, I got to know the people behind the code through our review discussions.

### Open Source Contributions and Growth

I contributed to request-scoped context in the Agent Gateway. Alongside my interest in how a gateway aggregates MCP tools, that work got me thinking about a different question: what information belongs to a single request as it moves through the gateway? Discussing changes with reviewers taught me to explain those boundaries in a pull request so others can follow the reasoning behind the code.

### Acknowledgements

Thank you to my mentor, Hongyu Liu (Aias00), for guiding me through the technical work and helping me take part in community discussions. I'm also grateful to everyone who read my patches, asked questions, and took the time to suggest changes.

### Looking Ahead

As a committer, I want to keep maintaining the Agent Gateway code and spend more time reviewing pull requests. I also hope to share what I learn about MCP and tool aggregation, and to help new contributors find their way into the project, much as others helped me during OSPP.
